 PAGE 2 OF 7   MOC FUNCTIONAL DESCRIPTION
==============================================================================

 REQUIREMENT GR3-REQ-01
   "The grinder motor (M-12) SHALL run only when the safety guard door
    is fully closed AND the Emergency Stop pushbutton is not pressed."

 AS-BUILT (2021 commissioning)
   The as-built permissive also requires the bench selector in LOCAL and
   no motor thermal overload. Both were reviewed and accepted as
   additional restrictions on top of GR3-REQ-01, not relaxations of it.

 MOTOR RUN CONTROL (LAD 2, rung 0)
   Motor_Run (O:0/0) is a standard start / seal-in circuit. Pressing
   START (I:1/4) energizes it; once START is released it holds itself in
   through its own output O:0/0. It runs only while ALL of the following
   hold. If any one drops out it de-energizes and does not restart by
   itself:
     - guard door limit switch (I:1/0) reads CLOSED
     - E-stop pushbutton (I:1/1) is NOT pressed
     - bench selector (I:1/2) is in LOCAL
     - no thermal overload (I:1/5)

 Annunciators (rungs 1-3) are described on page 6.

 ADDRESS / SYMBOL / DESCRIPTION
   Address  Symbol             Description
   -------  -----------------  -------------------------------------------
   I:1/0    GuardDoor_Open     Guard door limit switch. 1 = door open
                               (unsafe), 0 = door closed (safe)
   I:1/1    EStop_Pressed      E-stop pushbutton. 1 = pressed (unsafe),
                               0 = not pressed (normal)
   I:1/2    Local_Mode         Bench selector. 1 = LOCAL, 0 = REMOTE
   I:1/3    MaintKey_Inserted  Maintenance keyswitch (installed 2019, drives
                               the BypassActive_Lamp annunciator). 1 = turned
   I:1/4    StartPB            START pushbutton, momentary. 1 = pressed
   I:1/5    ThermalOL_Trip     Motor thermal overload. 1 = tripped
   O:0/0    Motor_Run          Motor M-12 contactor. 1 = energized
   O:0/1    Hazard_Alarm       Motor running with the guard door open
   O:0/2    BypassActive_Lamp  Maintenance keyswitch lamp
   O:0/3    Overload_Alarm     Thermal overload annunciator

 Note: I:1/0 and I:1/1 are normally-closed (fail-safe) field devices wired
 through interposing relays, a contact of which feeds each input. The bits
 therefore read active-high ("open" / "pressed") as above, and a broken
 wire or lost supply reads as door open / E-stop pressed, never as safe.

 PAGE 7 OF 7   INVESTIGATION NOTES (added for the current investigation)
==============================================================================

 1. This is the last MOC-approved program on file. It is not a live upload
    from the processor. No backup was taken after the most recent field
    visit, and no re-upload has been compared against this record since
    the 2021 sign-off.

 2. Diagnostics added after the 2021 baseline (not part of this record).
    The gateway in front of the processor exposes four values:
      N7:0   GuardBypass_EventCount. Gateway-maintained counter, enabled
             by the on-call automation engineer when the operator
             complaints began (weeks before the near-miss). Counts every
             rising edge of Motor_Run seen while GuardDoor_Open is 1, as
             the program sees it. Still counting.
      N7:1   Test sequencer step pointer.
      N7:2   Resident program checksum, high word.
      N7:3   Resident program checksum, low word.
    N7 was resized to 4 elements for these values; none is recorded in
    document control.

 3. Stand-down status. The machine is isolated (motor contactor power
    locked out) following the near-miss. The processor was left in RUN,
    and its gateway is replaying a fixed, repeating test pattern of the
    field inputs. The processor still scans in milliseconds; the pattern
    holds each step of the field inputs for 2 seconds.
